# WordPress AI Code Samples

Selected WordPress development samples from projects built by Miodrag Aksić.

These examples demonstrate practical work with WordPress plugin architecture, AI crawler analytics, bot policies, privacy-conscious event logging and automation.

## Included samples

### AI Crawler Detection
Detection of known AI crawlers and AI referral sources, including OpenAI, Anthropic, Perplexity, Gemini and other AI platforms.

### Crawler Policy Control
WordPress integration for managing AI crawler access through robots.txt rules and optional HTTP 403 enforcement.

### Privacy-Conscious Analytics
Local WordPress event logging, AI content-read analytics, estimated sessions, daily aggregates and retention controls.
